# UFood — Restaurant Discovery Web Application

A collaborative web application developed as part of a university software engineering project at Université Laval.

## Overview

UFood is a restaurant discovery and social web application built with Vue.js and TypeScript. It provides an interface for exploring restaurants, managing favorites, and interacting with other users.

## Features

- Restaurant search and discovery
- Restaurant information and interactive maps
- User authentication and profiles
- Favorite restaurants and collections
- Restaurant visit tracking
- Social features, including following other users

## Tech Stack

- **Frontend:** Vue.js, TypeScript, HTML, CSS
- **API Integration:** REST APIs
- **State Management:** Vuex
- **Routing:** Vue Router
- **Development Tools:** Git, npm, Vue CLI

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

```bash
git clone https://github.com/AlouCoul/UFood-Restaurant-Web-App.git
cd UFood-Restaurant-Web-App
npm install
npm run serve
```

Some functionality may depend on external API services.

## Project Context

This application was developed collaboratively as part of the GLO-3102 university course at Université Laval.

The repository is presented as an academic team project and demonstrates practical experience with component-based frontend development, TypeScript, API integration, and collaborative software engineering.
